# Physiological-Signals
Physiological signal based emotion/engagement analysis - Music for Babies

This project implements a real-time physiological signal processing pipeline to estimate:

❤️ Arousal (level of activation)
💙 Valence (emotional positivity/negativity)

The system processes data from wearable sensors (e.g., EmotiBit) using EDA (Electrodermal Activity) and Heart Rate (HR) signals and outputs continuous affective states.
